# Kanye West Album Database

A fan-made website dedicated to the discography of **Kanye West**, featuring his albums, tracklists, release years and links to individual songs on YouTube.

## About the Project

Kanye West Album Database is an independent web development project created to explore and showcase Kanye West's musical discography through a simple and accessible interface.

The website features a collection of album pages, each with its own visual design, containing tracklists and links to individual songs on YouTube.

The project was built from scratch as a personal portfolio project, with a focus on frontend development, organization and visual design.

## Features

- Album collection with release years.
- Dedicated pages for individual albums.
- Tracklists with song durations.
- Direct links to songs on YouTube.
- Custom backgrounds and visual elements for album pages.
- Responsive layout for different screen sizes.

## Technologies

- **HTML5** – Website structure and content.
- **CSS3** – Styling, layouts, animations and responsive design.
- **JavaScript** – Dynamic content and interactive elements.

## Getting Started

To explore the project locally:
1. Clone or download this repository.
2. Open the project folder.
3. Open index.html in your browser.
No additional dependencies or installations are required.
